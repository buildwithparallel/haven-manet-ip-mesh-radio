My Link

Tune the node you're connected to: its placement, its antenna and its link back to the gate.

How to use it
  1. Join the Wi-Fi of the node you want to tune. You are on confirms which node that is.
  2. Watch HaLow signal while you move the node, raise it, or adjust or swap its antenna. It updates every few seconds; closer to zero is better (−50 dBm strong, −80 dBm weak).
  3. Check Route to the gate: direct (one hop) is best. If it's relaying through other nodes, a better spot or antenna may get it a direct link.
  4. Internet, from the gate pings public DNS servers (Cloudflare, Google, Quad9) every 5 seconds. Lines coming back means traffic gets across the mesh and out to the internet.
  5. Stand still and press Run test to measure speed from this node to the gate. Run it before and after a change to compare.

Good to know: the speed test stops at the gate, so it measures the mesh, not your internet line. If the pings fail but the speed test works, look at the gate's uplink.

    Mesh

    Every node on your mesh, refreshed every few seconds.

    How to use it
    1. Each card is one node: its name, hardware, mesh address and transmit power (TX).
    2. The route under the name is how that node reaches the gate. Direct is one HaLow hop; Relayed goes through other nodes.
    3. The table lists the neighbors it hears. Signal: −50 dBm is strong, −80 dBm is weak. Sends and Receives are the HaLow link speed each way.

    Good to know: a node that's missing is off, out of range, or doesn't have the Toolchain's node agent installed.

    Paused: nothing is checking the nodes. Press Start to see them live.

    Route

    See what the mesh routing, batman-adv (B.A.T.M.A.N. V), is doing: the path it picked from a node to the gate, and how it changes. Use it to debug routes and to show self-healing.

    How to use it
    1. Pick a node to watch. The bright, moving line is the path batman-adv is using right now; dashed lines are backup paths it knows about.
    2. Paths the gate knows lists every path with its estimated speed. batman-adv uses the fastest, so this shows why it picked the path it did.
    3. Cover a relay node's antenna or switch it off. The line turns red, then jumps to a backup path, and Rerouted in shows how long that took.
    4. What happened logs every change, to catch a route that keeps flapping or a node that drops out.
    5. Present full screen shows just the diagram, for a laptop or TV.

    Good to know: batman-adv checks every path about once a second, from small messages each node sends. A slow reroute usually means the dropped link took a few seconds to be noticed as gone.

    Paused: nothing is tracing routes. Press Start to watch them live.

      Talk

      Push-to-talk voice between phones on the mesh. No internet or cell service needed.

      How to use it
      1. Enter your name and press Join. Allow the microphone to talk, or decline it to only listen.
      2. Hold the big button, or the space bar on a laptop, while you speak.
      3. Everyone who has joined hears you, whichever node's Wi-Fi they're on.

      Good to know: the count track at the bottom is a test: the gate plays someone counting, so a skip in the count shows the moment the mesh rerouted.

        ADS-B

        Live aircraft overhead, picked up by a node with an RTL-SDR, on a map that works with no internet.

        How to use it
        1. Aircraft broadcast their position, altitude and speed on 1090 MHz (ADS-B). The node decodes them and puts them on the map, with the trail each one has flown.
        2. The list shows every aircraft heard in the last minute, the most recent first. Tap one to find it on the map.
        3. Tap an aircraft on the map for its details. The map is built in, so it works with no internet.
        4. The same aircraft go to ATAK on the mesh as map markers (CoT), so a team sees them next to each other.

        Good to know: ADS-B and the SDR tab share the node's RTL-SDR. While anyone has the SDR tab open, ADS-B pauses and this map stops updating; it comes back 30 seconds after they leave. Range depends on the antenna: a 1090 MHz antenna up high hears aircraft over 100 miles away.

        SDR

        Signals intelligence (SIGINT) from a node with an RTL-SDR plugged in: find active networks in the area and work out what they are.

        How to use it
        1. Scan band: pick a band and press Start. A signal that keeps coming back at one frequency is an active network. The orange line holds the strongest signal seen.
        2. Tap a signal to zoom in on it. Zoom in shows about 2 MHz live, fast enough to see LoRa chirps: the diagonal lines inside a burst.
        3. Press Identify and make the radio transmit (for Reticulum, send an announce). The node listens for 6 seconds and tests every burst it hears: LoRa, with its bandwidth, spreading factor (SF), and coding rate; FSK; wideband signals like Wi-Fi HaLow; or a steady carrier. It also says when the settings match Meshtastic or LoRaWAN.
        4. Use what it found to set up a radio and try to talk to it. To measure by hand instead, press Freeze and drag a box across one chirp: its width is the bandwidth and its length gives the SF.

        Good to know: this only listens; it never transmits. While the SDR is in use, the node pauses ADS-B, and restarts it 30 seconds after you leave this tab. A strong transmitter next to the SDR, like the node's own HaLow radio, can swamp it: lower the gain or move the antennas apart.

        Looking for nodes with an SDR…
        Gain is how much the receiver amplifies. Use 0–10 dB when a transmitter close by swamps the view, and 30–40 dB to pick up distant signals. Auto gain lets the radio choose and keep changing it, so levels jump around and signals are hard to compare; a fixed number is better for hunting.

        Parallel Toolchain

        Live tools for your Haven mesh. Your gate node serves this page, so it works with no internet. Open it from any phone or laptop on a Haven node's Wi-Fi. Each tool stays idle until you press Start, so nothing uses the mesh when nobody's looking.

        The tools
        Words to know
        Gate
        The node with the internet uplink. This page runs on it.
        Point
        Any other node. Points pass traffic to each other and to the gate.
        HaLow
        The long-range Wi-Fi, around 900 MHz, that nodes use to reach each other.
        Hop
        One HaLow link. Direct means one hop to the gate; relayed means through other nodes.
        dBm
        Signal strength. Closer to zero is stronger: −50 is strong, −80 is weak, below −90 drops out.
        Mb/s
        Speed, in megabits per second.
